# A股涨跌预测系统

用 **Python (Flask) + Vue 3** 构建的 A股涨跌预测网站。基于 27 个技术指标（MACD/RSI/KDJ/均线等）作为特征，用 **5 模型堆叠集成**（XGBoost GPU + 随机森林 + 极端随机树 + AdaBoost + 逻辑回归）预测股票未来 1 / 5 / 20 个交易日的上涨概率。

---

## Quick Start

```bash
# 双击 start.bat 启动服务 (自动打开浏览器)
# 双击 stop.bat 关闭服务
```

**访问地址**: http://localhost:5173

## 数据源

所有数据均来自**公开的财经数据接口**，非模拟数据。

| 数据 | 来源 | API | 说明 |
|------|------|-----|------|
| **历史日线K线** | 腾讯行情 | `web.ifzq.gtimg.cn` | 前复权，最多约3年数据 |
| **实时行情** | 腾讯行情 | `qt.gtimg.cn` | 现价、涨跌幅、开高低收 |
| **大盘指数** | 腾讯行情 | `qt.gtimg.cn` | 上证/深成/创业板/科创50/沪深300 |
| **股票搜索** | 东方财富 | akshare `stock_info_a_code_name` | 全市场5500+股票代码表 |
| **个股行业** | 东方财富F10 | `emweb.securities.eastmoney.com` | 所属行业分类 |
| **行业板块** | 同花顺 | akshare `stock_board_industry_summary_ths` | 90个行业板块实时涨跌 |

### 数据缓存策略
- **历史K线**: `lru_cache(maxsize=256)`，进程级缓存，不重启一直有效
- **股票代码表**: 内存缓存，6小时刷新一次
- **大盘指数**: 60秒缓存
- **行业板块**: 5分钟缓存
- **个股行业**: 每个代码拉取一次后永久缓存
- **回测结果**: 5分钟缓存

## 预测模型

### 模型架构：多模型堆叠 (Stacking)

```
                     ┌── XGBoost (GPU) ──────┐
                     ├── 随机森林 ────────────┤
特征输入(27个指标) ───┼── 极端随机树 ──────────┼──→ 各自输出上涨概率
                     ├── AdaBoost ───────────┤
                     └── 逻辑回归 ───────────┘
                              │  (2折交叉验证生成元特征)
                              ↓
                     逻辑回归元模型 ← 学习5个模型概率的最优权重
                              │
                     ┌───────┴───────┐
                     ▼               ▼
                 综合上涨概率   回测准确率
               (1/5/20日)      (近30日)
```

### 基础模型说明

| 模型 | 类型 | 加速方式 | 特点 |
|------|------|----------|------|
| **XGBoost** | 梯度提升树 | **GPU (CUDA)** | 高效、正则化好、GPU加速训练 |
| **随机森林** | 装袋集成 | CPU 多核 (n_jobs=-1) | 稳健、抗过拟合 |
| **极端随机树** | 随机化集成 | CPU 多核 (n_jobs=-1) | 分裂阈值也随机化，增加多样性 |
| **AdaBoost** | 自适应提升 | CPU | 聚焦难分类样本 |
| **逻辑回归** | 线性模型 | CPU | 提供完全不同的线性决策边界 |

### 元模型
- **类型**: 逻辑回归 (LogisticRegression)
- **输入**: 5个基础模型对每个样本的预测概率
- **输出**: 综合上涨概率
- **防过拟合**: StackingClassifier 内部使用 **2折交叉验证** 生成元特征，避免元模型学到基础模型"背答案"的假规律

### 训练数据

| 参数 | 值 |
|------|-----|
| 训练股票 | **100 只**（横跨银行、白酒、新能源、医药、半导体、科技、券商、消费、能源、地产等 20+ 行业） |
| 每只股票历史 | 约 2000 个交易日（前复权） |
| 总样本量 | 约 5 万条/周期 |
| 特征维度 | 27 个技术指标 |
| 预测周期 | 1日 / 5日 / 20日（3个独立模型） |

### 特征列表 (27个)

| 类别 | 特征 | 数量 |
|------|------|------|
| **收益率** | 1/3/5/10/20 日涨跌幅 | 5 |
| **均线** | MA5/10/20/60 及股价相对均线的乖离率 | 8 |
| **MACD** | DIF、DEA、柱状值 | 3 |
| **RSI** | 6/12/24 日相对强弱指数 | 3 |
| **KDJ** | K、D、J 三线 | 3 |
| **量能** | 量比（当日成交量/5日均量） | 1 |
| **波动率** | 20 日收益标准差 | 1 |
| **价格位置** | 20 日区间位置、52 周高低位置 | 2 |
| **其他** | 价格距52周高/低位置 | 1 |

### 训练流程

```
启动服务
    ↓
检查模型文件 (models/stack_*.pkl)
    ↓
┌─ 文件存在且版本匹配? ───────────────────┐
│ 是 → 加载到内存 (约1秒)                  │
│ 否 → 开始后台训练                       │
│      ↓                                  │
│  ① 拉取100只股票历史K线 (8线程并行, ~60s)│
│  ② 计算27个指标特征 (~30s)              │
│  ③ 堆叠训练 (GPU+CPU, ~5min)            │
│      - XGBoost GPU 训练                  │
│      - 随机森林/极端随机树/AdaBoost 训练  │
│      - 逻辑回归训练                      │
│      - 2折交叉验证生成元特征              │
│      - 训练元模型 (逻辑回归)              │
│  ④ 保存到磁盘 (models/stack_*.pkl)      │
└──────────────────────────────────────────┘
```

**首次启动**会自动触发训练，**CPU+GPU 满载约 5-7 分钟**。训练完成后模型常驻内存，后续启动直接加载，无需重新训练。

## 预测流程详解

### 技术面预测 (核心)

```
用户输入股票代码 (如 600519)
    ↓
拉取该股历史日线 (腾讯, 前复权, 400天)
    ↓
计算最新一天的27个指标 (indicators.py)
    ↓
喂给堆叠模型 (5个基础模型各自预测, 元模型加权融合)
    ↓
输出 1日/5日/20日 上涨概率 + 方向 + 置信度
    ↓
同时拉取实时行情、大盘指数、板块涨跌、K线数据
    ↓
打包返回前端展示
```

### 回测准确率 (近30日)

```
对于近30个交易日中的每一天:
  用"截止该日"的数据计算指标 → 模型预测下一个交易日涨跌
  对比该日实际涨跌 → 正确/错误
    ↓
准确率 = 正确次数 / 30
    ↓
最近一次: 昨日预估 vs 今日实际 (显示在主页面)
```

### 技术信号生成

基于最新的指标值，生成可读的规则信号：
- **均线**: 股价站上/跌破20日均线
- **MACD**: DIF上穿/下穿DEA（金叉/死叉）
- **RSI6**: 超买(>80)/超卖(<20)/偏强/偏弱
- **KDJ**: K上穿/下穿D（金叉/死叉）
- **量能**: 放量/缩量

## 常见问题

### Q: 为什么打开页面后要等很久？
A: 首次打开需要从腾讯拉取历史K线数据。模型在服务器启动时已加载到内存，**刷新页面不需要重新加载模型**。所有数据有缓存，第二次打开就快了。

### Q: 为什么关闭页面重新打开又慢？
A: 浏览器每次都重新请求数据。但 Flask 后端有内存缓存，数据源请求只在第一次访问特定股票时发生。如果缓存未命中（比如重启了 Flask），需要重新从腾讯拉取。

### Q: 为什么 CPU 在第一次启动时满载？
A: 第一次启动时如果模型文件不存在，会自动触发后台训练：拉取 100 只股票数据 → 计算指标 → 训练 5 个基础模型 + 元模型，这个过程 CPU 和 GPU 都会满载约 5-7 分钟。训练完成后会自动恢复正常。

### Q: 预测准确率为什么只有 50% 左右？
A: 股票短期涨跌接近随机游走，这是市场本身的特性，不是模型的问题。50% 对短期涨跌预测来说是正常水平。模型通过回测给出了真实准确率，没有虚报。

### Q: 预测结果是基于什么？
A: 仅基于**技术指标**（价格和成交量数据），没有纳入基本面、新闻、政策等信息。模型只学习"历史价格形态与未来涨跌的相关性"。

### Q: 支持哪些股票？
A: 所有 A 股（上海、深圳、北京证券交易所），共 5500+ 只。输入 6 位股票代码即可查询。

### Q: 数据是实时还是模拟？
A: 全部是**真实市场数据**。历史K线来自腾讯行情，实时行情也是腾讯接口，板块数据来自同花顺。没有任何模拟数据。
